# Dataset requirements

Some original course inputs are not stored in this repository. Restore these files from your own course materials before rerunning the relevant notebooks. Their original publishers and reuse permissions have not been recorded here, so do not substitute unrelated datasets or publish private data.

| Notebook | Expected input | Location |
|---|---|---|
| `employee-workforce-analysis.ipynb` | `ABC Company.xlsx` | Repository root |
| `customer-retention-statistics.ipynb` | `customer_behavior.csv` | Repository root |
| `data-cleaning-and-preprocessing.ipynb` | `Employee.csv` | Repository root |
| `wine-quality-mathematics.ipynb` | `winequalityred.csv` (semicolon separated) | Repository root |

Other notebooks load example data through Seaborn or scikit-learn, or construct small examples in code. Internet access can be required for an initial download. The California housing case study should be run from its own subfolder.

When a dataset is restored, record its original source, access instructions, column definitions, and any reuse conditions. Rerun the notebook from a fresh kernel and review its outputs before publishing new conclusions.
